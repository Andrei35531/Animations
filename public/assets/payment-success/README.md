# Payment success animation assets

Place transparent PNG/WebP files here:

| File | Required | Description |
|------|----------|-------------|
| `jar.png` | **Yes** | Transparent glass jar (bowl + rim). Alpha = glass shape. Coins show through transparent areas. |
| `jar-front.png` | Optional | Front reflections/highlights only (screen blend). If omitted, CSS highlights are used. |
| `coin.png` | Included | Single ruble coin (extracted from reference). Replace to change coin look. |

Recommended jar size: ~512×560 px, transparent background.

Do **not** use storyboard frames as jar assets.
